# ההנחיות הקוליות

כאן נכנסים קבצי האודיו של הנגן שבראש כל תחנה.

**שמות הקבצים:** `01.mp3` … `07.mp3` — לפי מספר התחנה.

**אורך מומלץ:** כדקה. התגית בנגן מציגה את האורך האמיתי של הקובץ,
כך שאם תקליטי 80 שניות היא תגיד 80.

**אם אין קובץ** לתחנה מסוימת — הנגן פשוט לא יופיע שם. הדף לא נשבר,
ואפשר להעלות את הקבצים אחד־אחד לפי הקצב שלך.

**פורמט:** mp3. להמרה מהקלטה של האייפון:
`ffmpeg -i הקלטה.m4a -codec:a libmp3lame -q:a 4 01.mp3`
